# Отложенные инструменты Pi Desktop

Для Pi 1.0.4 дополнительные инструменты регистрируются с `exposure: deferred`.
Браузер, Web Access, ComfyUI, MCP и Pi Lens обнаруживаются штатным `codemode`:
`searchTools`, `describeTool`, `describeNamespace`, затем `tools.<name>(args)`.
Описание приходит результатом вызова, а не новой схемой в начале запроса.
Основные файловые, терминальные инструменты, цель, план и блокнот остаются прямыми.

Общая политика применяется при регистрации, включая инструменты новых аддонов
и подключённых MCP-серверов. Явные ограничения автора `hidden` и `model-only`
сохраняются. Старые активаторы схем скрыты; аддон Lens All Tools удалён,
его старые подключения очищаются при запуске.
Поиск использует английские ключевые слова: штатный индекс Pi ориентирован на них.

Выполнение идёт через штатный `ctx.executeTool`: валидация, обработчики разрешений,
отмена и события остаются действующими. Для инструментов без `outputSchema`
добавляется структурированный конверт `{content, details, isError}`, чтобы scripts
получали не только текст, но и изображения и сведения о файлах. Авторская схема
результата не заменяется. Изображения выводятся через `image(block)`, не `text`.
Результаты вложенной генерации сохраняются в `desktopNestedMedia` родительского
результата; выбор треков и просмотр медиа работают после возобновления чата.

Политика загрузчика включается только с `PI_DESKTOP_TOOL_ROUTING=1`, который задаёт
Pi Desktop. Установочный скрипт и обновление runtime применяют одну и ту же правку;
неизвестная версия/структура загрузчика требует проверки, а не слепой замены.
Ресурсы входят в существующий шаблон упаковки `resources/**/*`.

Проверка: `node --experimental-strip-types --test scripts/tool-routing.test.mjs scripts/pi-core-upgrade.test.mjs scripts/music-publication.test.mjs`.
RPC-тест запускает настоящее ядро с аддонами и тестовым HTTP-провайдером: проверяет
стабильность схем и префикса сообщений, поиск, вложенное выполнение, изображения,
сохранение медиа, блокировку разрешением, валидацию, STOP и reload.
Это не испытание качества локальной модели и не проверка упакованного Electron.
Стабильность обнаружения не гарантирует отсутствие пересчётов по другим причинам:
смена конфигурации, компактизация, перезапуск сервера или вытеснение KV-кэша.

Основа: [штатный codemode Pi](https://github.com/earendil-works/pi/blob/v1.0.4/packages/coding-agent/docs/codemode.md).
