# MCP Adapter 5.1.0 в Pi Desktop

Обновлён с 2.26.0. Используются штатные отложенные инструменты, ограничения
вывода, авторизация, проверки доверия проекта и разрешения вызовов.
`mcpScript` больше не нужен: скрипты выполняются через штатный `codemode`.

Сохранены только недостающие возможности:

- `mcp({action:"config"})`: реальные источники конфигурации и безопасные
  параметры подключения, без аргументов команд, паролей и токенов.
- `mcp({connect:"server"})`: проверка файлов и перечитывание изменённого
  определения. При изменении запускается штатная инициализация MCP с проверками
  доверия; переписка и основной процесс Pi не перезапускаются. MCP-подключения
  и временные разрешения при этом пересоздаются. Некорректный JSON не отключает
  действующие соединения.
- Постоянное описание шлюза: список серверов и инструментов обнаруживается
  результатами вызовов, без изменения схем в префиксе запросов модели.
- Вложенные причины ошибки подключения (`cause`, `code`) с маскировкой секретов.
  Штатные улучшения защиты заголовков в 5.1.0 остаются действующими.

Удалена старая ручная подмена определения и выборочная очистка метаданных:
она не учитывала новый жизненный цикл и проверки разрешений версии 5.
Подсказка теперь описывает `codemode` и штатный `action:"install"`.

Проверки запускают настоящий Pi с тестовым провайдером и локальным stdio
MCP-сервером: конфигурация изменяется во время сессии, новый сервер подключается,
схемы и предшествующие сообщения не меняются. Дополнительно проверены плохой
конфиг, диагностика, маскировка секретов, STOP и reload. Это не сборка Electron
и не проверка подключения к пользовательскому Godot.
