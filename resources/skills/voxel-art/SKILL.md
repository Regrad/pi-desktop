# Voxel art

Use only for the requested art task in this chat. Discover the MCP gateway
through codemode and connect `mcp({server:"froxel"})`. Read the current server
instructions and tool schemas. Do not assume a fixed tool inventory or a
developer's executable path. Pi Desktop uses a separate headless document
for each chat by default. Reopen a saved `.vox` when continuing earlier work.

1. Inspect references and existing project assets. Establish voxel scale,
   palette, target view, moving parts and export format from the brief.
2. Block out the complete silhouette and proportions. Hand sculpt one-off
   creatures and props with shapes and cell edits. Use parameterized scripts
   for repeated structures or families of variants when appropriate.
3. Inspect the document and active object before edits. Respect the current
   server's distinction between local cells and world coordinates.
4. Preview after every significant stage. Compare front, side and rear views
   against the reference, checking the whole figure, materials and empty
   spaces. Fix concrete differences before adding decorative detail.
5. Add bones and animation only when requested. Verify pivots, bindings,
   clipping and poses through previews.
6. Save the editable `.vox`, render a useful PNG and export `.glb` if needed.
   Check the actual files and requested scale. Show the result and paths.

An explicitly configured window mode uses Froxel's connected editor. That
window is shared, so do not replace an existing document without the user's
authorization. Do not use an unrelated project's customized Froxel fork as
the default editor for other projects.
