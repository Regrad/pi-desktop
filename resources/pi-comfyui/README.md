# ComfyUI — специализированные инструменты

Каждый инструмент регистрируется отдельным модулем `tools/<имя>/index.ts`: описание, схема параметров, привязка к workflow и обработка результата. Большие шаблоны и общие для семейства настройки располагаются рядом с инструментом. Общая библиотека отвечает за соединение, загрузку входов, ожидание, отмену и сохранение файлов; ядро Pi Desktop не интерпретирует графы.

Поддерживаются изображения Qwen, маски SAM/BiRefNet, музыка YuE2, речь OmniVoice, генерация 3D Pixal3D/Trellis2, PBR-текстурирование UltraTex, обработка, LOD и экспорт моделей.

Загрузчик автоматически находит модули; перед регистрацией проверяет их все и запрещает повторяющиеся имена. Опциональные схемы открываются модели через codemode по необходимости. Подготовки карточек, универсального запуска графов и отдельных модельных запросов нет.

Настройки подключения находятся в `data/comfyui.json`. Рабочий аддон — `data/agent/extensions/pi-comfyui`; штатные обновления сохраняют пользовательские изменения. Результаты принадлежат своему чату. Собственные API-профили совместимых инструментов используют явные placeholders, а не автоматически угаданные параметры.

Для модели операции называются `media_*`: описания содержат назначение, входы и параметры. Адрес сервера, графы и узлы остаются деталями реализации. Внутренние ошибки записываются в `data/logs/media-tools`, инструмент возвращает краткий отказ с идентификатором диагностики. Старые имена поддерживаются при показе сохранённых чатов; новые вызовы используют `media_*`.
