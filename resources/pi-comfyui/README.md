# ComfyUI — один аддон Pi Desktop

Рабочая копия после первого запуска новой версии приложения:
`data/agent/extensions/pi-comfyui/` рядом с портативной сборкой.
Она загружается штатным механизмом расширений Pi. Не нужно устанавливать Node.js отдельно.
В `resources/pi-comfyui/` находится исходный шаблон для первой установки, не рабочая копия.

```text
pi-comfyui/
  package.json
  index.ts                 # обнаруживает tools/*/index.ts автоматически
  tools/
    comfyui_generate_music/
      index.ts             # имя, описание для модели, схема параметров, выполнение
      workflow.ts          # API-граф этого инструмента
    comfyui_cover_music/
      index.ts
      workflow.ts
    comfyui_generate_3d/
      index.ts
      workflows.ts         # одно изображение / несколько ракурсов
    ...                    # все остальные инструменты
  lib/                     # общий клиент, обработка файлов, ABC и помощники
  shared/                  # общие типы и проверки
```

Все 25 инструментов находятся в отдельных папках. Несколько инструментов
редактирования изображений используют общий построитель графа в
`tools/comfyui_generate_image/workflow.ts`. Музыкальные инструменты используют общий
код обработки ABC в `lib/`. Этот код тоже часть редактируемого аддона, не приложения.

## Изменения и новые инструменты

### Речь OmniVoice

- `comfyui_design_voice`: создание голоса без образца и озвучивание текста.
- `comfyui_clone_voice`: новые реплики по аудиообразцу и его точной расшифровке.
  Если расшифровка неизвестна, явно включите `auto_transcribe`: Whisper может
  потребовать скачивания, его результат нужно проверять.

Оба используют локальную OmniVoice, bfloat16, русский язык по умолчанию.
Доступны все официальные категории атрибутов: пол, возраст, высота, шёпот,
английский акцент и китайский диалект. Акцент действует только на английскую
речь, диалект — только на китайскую. `preset` задаёт начальную комбинацию,
отдельные поля её переопределяют; `instruct` принимает только официальные теги
на английском/китайском, не свободное описание. Конфликтующие теги отклоняются.
Произвольные эмоции и гарантированное управление русскими ударениями не обещаются.

Настройки: seed, num_step, guidance_scale, speed, duration, t_shift, denoise,
preprocess_prompt, postprocess_output, layer_penalty_factor, position_temperature,
class_temperature, audio_chunk_duration, audio_chunk_threshold, normalize_text,
pad_duration, fade_duration, device, dtype. `duration=0` — автоматически;
положительная длительность переопределяет speed. Не рассчитывайте её без запроса.
`normalize_text` по умолчанию выключен; русские числа обрабатываются num2words,
расширенная нормализация английского/китайского требует WeTextProcessing.
pad_duration и fade_duration задаются отдельно от удаления тишины.

Сам текст реплики — на нужном языке. Сохранённое аудио возвращается плеером
в чат и хранится в `data/music-generation` вместе с другими аудиорезультатами.
Для постоянного голоса персонажа используйте один и тот же аудиообразец;
seed сам по себе не фиксирует личность голоса. Клонирование загружает образец
в ComfyUI автоматически. После установки перезапустите Pi Desktop.

### Обработка 3D

- `comfyui_process_3d`: закрытие отверстий (WTiVo), quad-ретопология, упрощение,
  перенос текстур с исходной модели на целевую, normal/AO. Отдельный quad-OBJ;
  GLB остаётся треугольным. Отчёт содержит фактическую геометрию и предупреждения.
- `comfyui_texture_3d`: новая текстура по изображению через Trellis2MeshEncoder;
  параметры seed, шагов, CFG, denoise, разрешений энкодера/текстуры и UV.
- `comfyui_lod_3d`: до шести уровней детализации с отдельными GLB и картами.
- `comfyui_asset_3d`: очистка, компоненты, нормали, UV, экспорт и до 16 ракурсов.
  Рендеры возвращаются изображениями, чтобы языковая модель могла их осмотреть.

Генерация по одному/четырём изображениям дополнена `UniversalModelTools`:
по умолчанию финальное упрощение до примерно 30000 треугольников и перенос текстур
2048. Все настройки доступны через `postprocess`; старые настройки генерации
остались в `model3d_options`. Явный `target_face_count` также задаёт финальный
бюджет, если его не переопределяет `postprocess.target_triangles`.

Готовые GLB сохраняются в `data/3d-generation`, карты/OBJ — в подпапках задания;
ракурсы — в `data/image-generation`. JSON-отчёт содержит локальные пути.
Для самостоятельного OBJ сторонние текстуры могут потребовать ручного переноса:
загрузчик не следует ссылкам за пределами результата задания. Полный текстурный
результат — самодостаточный GLB. Утилиты не сохраняют риги и анимацию.

Обработка существующей модели требует доступа ComfyUI к её пути (тот же ПК или
общая файловая система); изображение загружается автоматически. Изменения вступают
в силу после перезапуска аддона/сессии, без перекомпиляции Pi Desktop.

### Выбор треков для ответа

`comfyui_publish_music` принимает `tracks` — полный список абсолютных путей к готовым
аудиофайлам в `data/music-generation`. Модель явно выбирает, какие треки показать
в финальном ответе, включая файлы из предыдущих сообщений. Последний успешный вызов
заменяет весь выбор; `tracks: []` не публикует ни одного трека. Повторения удаляются,
порядок сохраняется. Файлы не копируются и не удаляются. Плееры появляются после
завершения ответа, до этого результаты остаются в инструментах. Упоминания имён
файлов в тексте не переопределяют явный выбор. Старые ответы без вызова этого
инструмента сохраняют прежний способ отображения.

### Редактирование аддона

Редактируйте UTF-8 файлы рабочей копии. После изменений перезапустите Pi Desktop,
чтобы заново загрузились инструменты и их инструкции. Активная сессия не подхватывает
изменения посреди вызова. Компиляция приложения не требуется.

Чтобы добавить инструмент, создайте `tools/comfyui_<name>/index.ts` и экспортируйте
по умолчанию функцию `register(pi, context)`. Она вызывает `pi.registerTool(...)`.
Список инструментов в главном файле менять не нужно. Используйте существующие
инструменты как образцы схем TypeBox и результатов. Одинаковые имена запрещены:
ошибка загрузки не оставляет частично зарегистрированный набор.

API workflow может быть `workflow.ts`, экспортирующим граф, либо соседним JSON,
прочитанным относительно `import.meta.url`, а не текущей папки проекта.
Новая модель не обязана иметь существующий `ComfyMode`: `lib/workflow.ts` предоставляет
`runApiWorkflow(dataDir, graph, { kind: "image" | "audio" | "model", outputNodes?, timeoutMinutes? }, signal, progress?)`.
Подготовьте граф и выставьте его входы в своём инструменте. Исполнитель проверяет
локальные узлы, ставит задание в очередь, ждёт и сохраняет результаты. `outputNodes`
позволяет выбрать финальные узлы, исключив промежуточные файлы.
Для загрузки входов доступен локальный HTTP-помощник `request` из `lib/comfy-client.ts`;
для изображений — `readImageInput` из `lib/image-input.ts`.

Результаты `runApiWorkflow`: `promptId`, `files`, `totalFiles`, `reports`.
Для изображений возвращайте image-блоки из `files[].data` и `details.files` с путями.
Для аудио/3D возвращайте `details.media` с полями `type` (`audio`/`model3d`),
`path`, `mimeType`. Имя инструмента с префиксом `comfyui_` обеспечивает отображение
медиа в чате существующим интерфейсом Pi Desktop.

Обновление приложения не перезаписывает рабочий аддон. Его удаление тоже сохраняется:
флаг первой установки находится в `data/builtin-config/pi-comfyui-installed.json`.
Для восстановления шаблона удалите этот флаг и папку аддона при закрытом приложении.
Аддоны исполняют код с доступом к файлам: устанавливайте только доверенные изменения.
